The Federal Communications Commission provides free public REST APIs for radio station license lookup, broadband coverage maps, spectrum auction data, broadcast contours, census block conversions, consumer complaint databases, electronic comment filings, and regulatory data. All APIs are free with no authentication required for most endpoints.

**Areas:** Federal Government · Telecommunications · Radio · Broadband · Spectrum · Licensing · Regulatory

## How this profile is made
